## 1. 这个形象要用在哪里（先理解这些）

| 事实 | 对模型的要求 |
|---|---|
| 屏幕是 2.0 英寸 IPS，320×240 像素（约 40.8 mm × 30.6 mm），RGB565（约 6.5 万色），主人在约 35 cm 外看 | 轮廓要清楚，眼睛要大，用卡通平涂或两三阶的赛璐璐着色，颜色控制在十来种。渐变会出现色带，细节越少越好。头发要成片成束，不要细丝（会锯齿和闪烁）。描边在 320×240 下至少 2 像素 |
| 屏幕是一扇「窗」，窗后是一个固定在头里、约 32 mm 深的小鱼缸，她在缸里 | 只需要半身像（胸口以上加一点手臂）。比例推荐 Q 版（头身比约 1:2 到 1:2.5），在小屏上更好认 |
| 机器人的头会左右转（舵机约 −144° 到 +169°），主人会从侧面、斜着看。以后她还要能在缸里整个转过身 | **模型必须 360° 完整**：后脑勺、背面的头发、背影、鲸鱼特征（头鳍、尾巴等）都要做，不能只做正面 |
| 她要能「回头看主人」：身体朝一个方向，头单独转过来 | 需要骨骼：至少有 `Hips → Spine → Chest → Neck → Head`，眼睛有 `LeftEye`、`RightEye` 骨骼或视线表情。头转 ±70°、低头抬头 ±30° 时，脖子和头发**不能穿模、不能撕裂**。头发必须绑在 Head 骨骼上，跟着头转 |
| 设备上现有的六种表情：neutral、happy、angry、sad、doubt、sleepy；以后要做口型 | 表情做成 blendshape（形态键），命名：`blink`、`blink_L`、`blink_R`、`happy`、`angry`、`sad`、`surprised`、`sleepy`、`aa`、`ih`、`ou`、`ee`、`oh`（VRM 的标准名也可以） |
| 帧都是在 Mac 上预先渲染好再存进设备的。设备帧库只有 4 MiB：一张整屏帧 150 KB，最多约 27 张；只画屏幕中间一块的话可以存更多 | 不需要物理模拟。头发骨骼（spring bone）是加分项，不是必需。渲染时画面主体要能放进屏幕中间约 220×200 像素的区域 |
| 设计以公开三视图为准：蓝色系头发，鲸鱼头鳍，呆毛，鲸鱼尾巴，女仆元素 | 外观一致比细节精美更重要 |

## 3. 选择做法（【问主人】选定后再动手）

按下面顺序评估，把每条路的预计效果、要装什么、要不要上网或付费列给主人，让主人选：

1. **（推荐）找一个授权允许改造的动漫风底模（VRM），改成鲸鱼娘。** VRM 自带标准骨骼、表情和头发骨骼，最适合「回头看」和表情。用 Blender 脚本完成三件事：
   - 改头发和衣服的颜色或贴图；
   - 加头鳍、尾巴等鲸鱼部件，绑到 Head 或 Hips 骨骼上；
   - 调成 Q 版比例。

   底模的授权必须允许修改，并且和 CC BY-NC-SA 兼容。
2. **用图生 3D 服务**（Tripo、Meshy、混元 3D 等）从三视图生成网格，再在 Blender 里绑骨骼。动漫头发常常会被做成一团，要检查能不能用。在线服务和费用都要【问主人】。
3. **主人自己用 VRoid Studio 捏人**（图形界面，免费），你负责后面的导出、检查和渲染脚本。

**完成标准：** 主人选了一条路，并在对话里写下来。

## 4. 制作

- 坐标约定：Y 朝上，正脸朝 +Z。单位用米，身高按 Q 版约 1.0。原点在脚底或 Hips。
- 交付 `.vrm`（VRM 1.0 或 0.x）或 `.glb`（glTF 2.0，贴图内嵌）。
  - 用 `.glb` 时，节点名必须照第 1 节的骨骼名。
  - 网格 5 万三角面以内。
- 材质用不依赖特殊着色器的基础颜色或卡通材质；描边用反向外壳网格或渲染时加描边。

**完成标准：**
- 文件能在 Blender 命令行里导入，没有报错；
- 骨骼和表情按名字都能找到；
- 背面完整；
- 头转 ±70° 时没有穿模。

## 5. 渲染脚本（照这个接口做，Claude 会直接调用）

提供 Blender 命令行脚本 `.local/whale-girl-3d/render_frame.py`，调用方式：

```
blender -b -P render_frame.py -- --model 模型路径 --psi 度 --alpha 度 --head-yaw 度 --head-pitch 度 --expression 名字 --out 输出.png
```

- `psi`：她整个身体相对窗的水平转角。0 是正对窗外的主人，正值是她转向**她自己的左边**（主人看到她的右脸）。
- `alpha`：主人眼睛偏离屏幕法线的角度。正值是主人在屏幕的右侧（站在屏幕前看）。
- `head-yaw` / `head-pitch`：头相对身体的转角，用来回头看主人。
- 输出：320×240 RGBA PNG，背景透明。只画她，不画鱼缸，Claude 会把她合成进鱼缸。建议先按 640×480 渲染再缩到 320×240 抗锯齿。

**相机必须严格照这个离轴投影做，否则和鱼缸、转头对不上：**

- 屏幕坐标：x 向右，y 向上，z 从屏幕指向主人，单位 mm。窗是 z=0 平面上中心在原点、40.8 × 30.6 的矩形。
- 主人眼睛 E = (350·sin α, 0, 350·cos α)。
- 在 Blender（Z 朝上）里用这个对应关系：Blender X = x，Blender Z = y，Blender Y = −z。相机放在 E，旋转 (90°, 0, 0)，也就是朝屏幕里看，不跟着 α 转。
- 相机参数：`sensor_fit='HORIZONTAL'`，`sensor_width=40.8`，`lens = E.z`（mm），`shift_x = −E.x/40.8`，`shift_y = −E.y/40.8`，分辨率 320×240（或它的整数倍）。
- 她站在缸里：身体中心在屏幕坐标约 (0, −2, −14) mm 处（可微调）。缩放到胸口以上大约占窗高度的 75%。实际用的位置和缩放写进 `manifest.json`。

**完成标准：** 渲染并保存下面这张联系表，自己逐项检查：

`.local/whale-girl-3d/contact-sheet.png` 包含：

- psi=0 时 α = −30、+30；
